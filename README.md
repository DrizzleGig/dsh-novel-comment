# dsh-novel-comment · AI 读者

DSH 插件：**一屋子只读到这一章的 AI 读者**。他们按自己的口味读你的稿子，给 **1–5 星 + 章评 + 段评**，追更或弃书，并把偏好沉淀成可复用的口味档案与按序评审链。

> 当前版本 **`0.5.0`**：5 个 Host 工具 + 右栏「AI 读者」面板（阅读档案 / 当前作品 / 日报 / 找书 四页签）。六类标签选择器、按标签找书、四档面板底色。默认模拟；配置模型端点后才真正调用模型。

## 安装

- 从 npm 安装：在 DSH「插件 → 添加插件」里填包名 `dsh-novel-comment`；
- 或本地安装：选择本目录 / 用插件管理器安装本目录。

装完重启一次 DSH，新会话里应能看到 `reader_*` 工具与右栏「AI 读者」页签。

> 右栏面板依赖宿主提供的 `@deepseek-ai/dsh-typert-protocol` 与 `@deepseek-ai/dsh-session`（DSH 自带，不用另装）。

## 它解决什么

- **上帝视角诅咒**：作者知道后文，容易高估铺垫；读者只有前文记忆，该困惑就困惑。
- **读者会弃书**：追更读者有耐心阈值与疲劳计数，能说「这里我会划走」。
- **口味相反**：多读者并排，分歧本身就是修改信号。
- **改稿后意见失效**：改稿会让该章及以后的评审链失效，重评必须按序。

## 工具

| 工具 | 做什么 |
|---|---|
| `reader_books` | `list` 看读者/书；`create` 建读者（模板 binge/emotion/plot 或自建人设，可带喜好/雷点标签）；`import` 导入作者稿章节 |
| `reader_review` | 真实评审一章（需模型配置）：严格校验星级/章评/段评定位/弃书原因，失败自动修复一次；只喂「读者已读到的前文 + 本章正文」，不注入后文 |
| `reader_rate` | 手工记一条读者评分（不调模型）：1–5 整星 + 章评 + 段评 + 追更/观望/弃书（弃书必填原因码） |
| `reader_report` | 生成某天的读者日报（`### <bookId>` 格式），可写入 `reports/<date>.md` |
| `reader_discover` | 按口味找书：喜好加权、雷点硬过滤、同作者/相似标签降权、排除已读已弃；真实书源未接入，`READER_SOURCE=fake` 才能用 |

## 右栏面板

- **阅读档案**：读者卡（档案版本 · 稿件版本徽标）、口味标签、评分历史与段评；
- **当前作品**：正文 + 星级 + 章评 + 段评 + 追更/观望/弃书 + 分歧归因 + 配额条；
- **日报**：按天汇总，可保存；
- **找书**：按口味推荐；支持「从公开链接导入（L2）」，只存 ≤300 字摘录；
- 面板宽度 <380px 时页签折叠为「档案 / 作品 / 日报 +1」。

## 配置（可选）

| 环境变量 | 作用 |
|---|---|
| `READER_LLM_BASE_URL` | OpenAI 兼容端点，如 `https://api.deepseek.com/v1` |
| `READER_LLM_MODEL` | 模型名，如 `deepseek-chat` |
| `READER_LLM_API_KEY` | Key（不写日志、不进提示词） |
| `READER_SOURCE=fake` | 启用内置假书源，用于演示/测试「按标签找书」 |
| `READER_PAGE_HOSTS` | 逗号分隔的公开页域名白名单（L2 导入用） |

不配置模型时：`reader_review` 会**明确报错**，不会假装评审；手工评分、日报、导入仍然可用。

## 数据边界

- 读者数据只写 `<工作区>/.dsh-novel-comment/`（读者、口味、评分、记忆、配额、日报）；全局读者索引在 `<DSH_HOME>/dsh-novel-comment/`。
- 不读不写其他 `.dsh-novel-*` 目录，不碰其他插件的账本。
- 评审只使用「读者已读到的前文记忆 + 本章正文」，不注入后文。
- 评分/日报不附外部作品正文；公开页导入只存 ≤300 字摘录。

## 已知限制

- 真实书源（番茄等）未接入；`reader_discover` 目前只有假书源。
- 真实模型调用需要你自己的端点/Key；本机发布验证使用脚本化模型端口，没有真实 API 调用。
- 真实 DSH 宿主、真书、真实站点/登录态验证按工作区规则后置；发布结论仅覆盖模拟/单测范围。
- 面板的 L2 公开链接导入已接通 remote 描述符，但真实站点抓取未验证（按工作区规则后置）。
